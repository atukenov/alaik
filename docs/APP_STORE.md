## App Review notes
```
Alaik uses email + password sign-in (no email verification step).

Demo account for review:
  email:    review@alaik.app   (or register a fresh account in-app)
  password: alaik-review-123

Flow to try:
  1. Register or sign in.
  2. Tap + to create an event and add a gift (paste any store link to auto-fill a photo).
  3. Open the event and tap Share to get the public guest link.
  4. Open that link — reserve a gift as a guest (no account needed).

Account deletion is available in-app: Profile → "Удалить аккаунт".
```

> Before submitting: create the `review@alaik.app` account on your live API (or tell the
> reviewer to register in-app), and host `PRIVACY.md` at a public URL.
