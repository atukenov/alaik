# Handoff: Alaik — мобильное приложение вишлистов

## Overview
Alaik — приложение, где владелец создаёт список желаемых подарков к событию (свадьба, день
рождения, baby shower, новоселье), а гости открывают список по публичной ссылке и «бронируют»
подарок, чтобы избежать дублей. Название — от казахского тёплого приглашающего возгласа.

Этот пакет описывает **UI/UX и визуальный язык MVP**. Полный технический стек, архитектура
бэкенда, структура данных и порядок работ вынесены в **`TECH_STACK.md`** (в этой же папке).

## About the Design Files
Файлы в этом бандле — **дизайн-референсы, сделанные в HTML** (интерактивные прототипы,
показывающие задуманный вид и поведение), **а не продакшн-код для копирования**. Задача —
**воссоздать эти экраны в целевом окружении**: React + TypeScript + Vite, обёрнутый в Capacitor,
UI на Ionic React + Tailwind CSS (см. `TECH_STACK.md`), следуя паттернам этой экосистемы.
HTML/inline-стили из прототипа переносятся в компоненты и Tailwind-классы, а не переиспользуются
дословно.

## Fidelity
**High-fidelity.** Финальные цвета, типографика, отступы, радиусы и интеракции. Воссоздавать
пиксель-в-пиксель средствами Ionic + Tailwind. Полосатые прямоугольники с моно-подписью
(`фото`, `обложка · 3:4`, `иллюстрация`) — это **плейсхолдеры под реальные изображения**,
не элемент дизайна.

## Выбранное визуальное направление: «Праздничный коралл»
Тёплое, современное, минималистичное, праздничное. Розово-белый фон, коралловый primary с
золотым вторичным акцентом, мягкие крупные скругления, шрифт Onest.

## Screens / Views
Приложение — стек из 7 экранов. Навигация: онбординг → auth → таб-бар (Списки/Профиль),
из таб-бара пуш-переходы в мастер, экран владельца, гостя. FAB по центру таб-бара = «создать».

### 1. Онбординг
3 слайда с плейсхолдером-иллюстрацией (квадрат 1:1, скругление 32px), заголовком и описанием.
Сверху: пилюля-переключатель языка (RU/KZ/EN, циклом) слева, «Пропустить» справа. Индикатор —
3 точки, активная вытянута в пилюлю `--accent` (22px), остальные 7px `--card2`. CTA внизу —
градиентная кнопка (54px, radius 100): «Далее», на последнем слайде «Начать» → auth.
Копия слайдов (RU): «Дарите то, что ждут», «Поделитесь ссылкой», «Сюрприз под защитой».

### 2. Auth (OTP)
Шаг phone: кнопка-назад (круг 40px, `--card2`), лого-плитка `a` с градиентом, заголовок
«Вход в Alaik», подзаголовок, поле с префиксом `+7` и инпутом номера (высота 54, radius 16,
border `--line`), внизу CTA «Продолжить» → шаг otp.
Шаг otp: заголовок «Введите код», 4 бокса-цифры (64px, radius 16, border `--accent`),
строка «Отправить снова · 0:47», CTA «Подтвердить» → Мои списки.

### 3. Мои списки (таб)
Заголовок «Привет, Аяна» + аватар-плейсхолдер (круг 42px). Сегмент-контрол (пилюля на фоне
`--card2`): «Мои» / «Где бронировал» — активный сегмент белый с тенью. Список карточек событий:
обложка-тинт 104px с чипом типа (коралловая пилюля), title + дата, трек прогресса (градиент),
подпись «N позиций закрыто · всего». Тап по карточке → экран владельца.
Нижний таб-бар: «Списки», центральный градиентный FAB `+` (50px, приподнят), «Профиль».

### 4. Мастер создания события
Хедер: назад + «Новое событие», прогресс из 2 сегментов.
Шаг 1 «Выберите тип события»: сетка 2×2 тайлов (обложка-тинт 78px + подпись), выбранный —
border 2px `--accent`. CTA «Продолжить».
Шаг 2 «Детали»: превью обложки выбранного типа с чипом, поле «Название», поле «Дата»
(«15 августа 2026»), CTA «Создать список» → экран владельца.

### 5. Список подарков (владелец) — ключевой UX
Обложка 170px с назад-кнопкой и заголовком события. Карточка **«Закрыто позиций 8 / 15»** с
прогрессом и пояснением: *«Кто именно забронировал — скрыто. Сюрприз останется сюрпризом.»*
Владелец видит **только процент/счётчик**, без имён и без пометки конкретных позиций.
Кнопка «Поделиться» → открыть как гость (превью). Секция «Подарки»: карточки (миниатюра, title,
цена, иконка `⋯` для редактирования) — **без** статуса брони. Внизу sticky CTA «Добавить подарок».

### 6. Публичный экран гостя — сердце продукта
Обложка 196px (декор-ромб золотой), чип типа, заголовок, «15 августа · Список от Аяны».
Карточка **«Выбрано подарков N / 5»** с живым прогрессом. Секция «Подарки», карточки:
- **свободна**: миниатюра, title, магазин, цена, кнопка `Забронировать` (коралл).
- **забронирована**: карточка `opacity .62`, на миниатюре ✓, вместо кнопки — «Забронировано ·
  отменить» (тап отменяет бронь). Кто забронировал — **не показывается** другим гостям.
Тап «Забронировать» меняет статус позиции и обновляет прогресс. Внизу sticky «Поделиться списком».

### 7. Профиль
Карточка пользователя (аватар, имя, телефон, «Изменить»). Две плитки-статистики: «Мои события 3»,
«Брони 2». Блок **«Язык»** — 3 кнопки RU/KZ/EN, активная залита `--accent` (интерфейс переключается
на лету, i18n — см. ниже). Список настроек: Уведомления, Настройки, Помощь, Выйти (красным).

## Interactions & Behavior
- Все переходы — смена экрана в стеке; появление экрана — анимация `fadein` (opacity + translateY 6px, .28s ease).
- Тап-фидбек на всех интерактивных элементах: `transform: scale(.97)` на :active, transition .12s.
- Бронирование — оптимистичный тумблер статуса позиции + пересчёт счётчика/прогресса; поддержана отмена.
- Прогресс-бары анимируют ширину (`transition: width .3s`).
- Владельцу имена/позиции броней не раскрываются нигде (инвариант приватности сюрприза).

## Internationalization (RU / KZ / EN)
Вся видимая копия — через словарь переводов (в прототипе — объект `tr` в логике
`Alaik Prototype.dc.html`, ключи `ru`/`kz`/`en`). В продакшене вынести в i18n-решение
(например `react-i18next`), дефолт — русский, переключатель в профиле + быстрый цикл на онбординге.
Имена, даты и цены (₸) в контенте остаются как данные. **Полные готовые строки для всех трёх языков
уже есть в объекте `tr`** — забрать оттуда.

## State Management (UI)
Локальный UI-стейт (в проде — Zustand): текущий экран/маршрут, язык, шаг онбординга, шаг auth,
номер телефона, сегмент списков, шаг мастера + выбранный тип, карта статусов броней (`itemId → bool`).
Данные (события, позиции, брони) — через React Query к API (см. `TECH_STACK.md`).

## Assets
Своих ассетов нет. Все изображения — плейсхолдеры (полосатый паттерн + моно-подпись): обложки
событий 3:4, миниатюры подарков, аватары, иллюстрации онбординга. Иконки в прототипе —
инлайн-SVG (назад, плюс, share, chevron, globe, tab-иконки); в проде заменить на иконки Ionic
(`ionicons`). Лого — временная плитка с буквой `a` на градиенте.
